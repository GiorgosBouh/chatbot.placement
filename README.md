# Οδηγός Πρακτικής Άσκησης · SE5117

Chatbot για τους φοιτητές Προπονητικής και Φυσικής Αγωγής του Μητροπολιτικού Κολλεγίου Θεσσαλονίκης.

## Έκδοση GitHub Pages

Διεύθυνση μετά την ενεργοποίηση και την επιτυχή δημοσίευση:

**https://giorgosbouh.github.io/chatbot.placement/**

Το περιβάλλον τρέχει στο GitHub Pages. Οι ερωτήσεις που πληκτρολογούνται στέλνονται στο backend Sites, που καλεί το **Groq (`openai/gpt-oss-20b`)** με τα σχετικά αποσπάσματα της βάσης γνώσης και το πρόσφατο ιστορικό συνομιλίας. Το κλειδί Groq υπάρχει μόνο ως server secret και δεν περιλαμβάνεται σε αρχεία ή αιτήματα του browser.

Οι συχνές ερωτήσεις εμφανίζουν άμεσα τις επιμελημένες απαντήσεις από τις 41 καταχωρίσεις του `qa_data.json`. Αν η υπηρεσία AI δεν είναι διαθέσιμη, η αναζήτηση λειτουργεί τοπικά, με εξομάλυνση ελληνικών τόνων, κεφαλαίων και τελικού σίγμα, συνώνυμα και ανοχή σε μικρά ορθογραφικά λάθη. Η εφαρμογή επισημαίνει αν η απάντηση προέρχεται από AI ή από τη βάση γνώσης.

Η εφαρμογή δεν αποθηκεύει συνομιλίες στον server. Όταν χρησιμοποιείται το AI, η ερώτηση και τα πρόσφατα μηνύματα διαβιβάζονται στο Groq· ισχύουν επίσης οι όροι και οι πολιτικές δεδομένων του παρόχου. Η σελίδα εμφανίζει σχετική ενημέρωση.

### Ενεργοποίηση δημοσίευσης

1. Στο αποθετήριο, άνοιξε **Settings → Pages**.
2. Στο **Build and deployment → Source**, επίλεξε **GitHub Actions**.
3. Στο **Actions → Deploy GitHub Pages**, πάτησε **Run workflow** αν η αρχική εκτέλεση απέτυχε πριν ενεργοποιηθεί το Pages.

Κάθε επόμενο push στο `main` ελέγχει την αναζήτηση και το backend και δημοσιεύει αυτόματα τη σελίδα. Το workflow ανεβάζει μόνο τα αρχεία της ιστοσελίδας, όχι το Python app, το backend ή τα PDF. Δεν απαιτούνται secrets στο GitHub Pages. Το backend δημοσιεύεται ξεχωριστά μέσω Sites.

### Τοπική προεπισκόπηση

```sh
python3 scripts/build_site.py
python3 -m http.server 8501 --directory _site
```

Άνοιξε `http://localhost:8501/`. Χρειάζεται HTTP server· το άνοιγμα του `index.html` ως `file://` δεν υποστηρίζει τη φόρτωση της βάσης γνώσης.

### Έλεγχοι

Με Node.js 22 ή νεότερο:

```sh
node --test tests/search.test.mjs
node --test backend/tests/chat.test.mjs
```

Οι έλεγχοι καλύπτουν όλες τις καταχωρίσεις, ελληνική κανονικοποίηση, σύντομες ερωτήσεις για ώρες και αμοιβή, αμφίσημες ερωτήσεις και αποχή όταν δεν υπάρχει σχετική απάντηση.

### Αρχεία

| Αρχείο | Ρόλος |

## Ενημέρωση περιεχομένου

Επεξεργάσου το `qa_data.json`, διατηρώντας μοναδικό αριθμητικό `id` και τα πεδία `category`, `question`, `answer`, `keywords`. Το επόμενο push ενημερώνει την ιστοσελίδα. Για αλλαγές στην ορολογία της αναζήτησης, πρόσθεσε συνώνυμα στο `search.mjs` και αντίστοιχο έλεγχο. Ενημέρωσε και δημοσίευσε επίσης το backend ώστε το LLM να χρησιμοποιεί την ίδια έκδοση γνώσης· δες `backend/README.md`.

**Προσοχή στις ημερομηνίες:** η υπάρχουσα βάση περιέχει πληροφορίες παλαιότερου ακαδημαϊκού έτους. Επιβεβαίωσε προθεσμίες και απαιτήσεις με τον υπεύθυνο πριν τις χρησιμοποιήσεις. Η ιστοσελίδα εμφανίζει σχετική επισήμανση. Τα επίσημα δικαιολογητικά υποβάλλονται στις πλατφόρμες του κολλεγίου.

## Αρχική εφαρμογή Streamlit

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Το GitHub Pages δεν εκτελεί Python. Η αρχική έκδοση `app.py` παραμένει διαθέσιμη για ξεχωριστή φιλοξενία Streamlit. Η έκδοση Pages χρησιμοποιεί το ξεχωριστό backend Sites για το LLM. **Μην τοποθετείς API keys σε JavaScript, HTML ή Git**.
