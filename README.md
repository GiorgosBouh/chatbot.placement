# Οδηγός Πρακτικής Άσκησης · SE5117

Chatbot για τους φοιτητές Προπονητικής και Φυσικής Αγωγής του Μητροπολιτικού Κολλεγίου Θεσσαλονίκης.

## Έκδοση GitHub Pages

Διεύθυνση μετά την ενεργοποίηση και την επιτυχή δημοσίευση:

**https://giorgosbouh.github.io/chatbot.placement/**

Η στατική έκδοση τρέχει εξ ολοκλήρου στον browser, χωρίς Python server ή API key. Χρησιμοποιεί τις 41 υπάρχουσες καταχωρίσεις του `qa_data.json`, με εξομάλυνση ελληνικών τόνων, κεφαλαίων και τελικού σίγμα, συνώνυμα και επιλογές για αμφίσημες ερωτήσεις. Οι απαντήσεις προέρχονται μόνο από τη βάση γνώσης. Οι ερωτήσεις δεν αποθηκεύονται ούτε αποστέλλονται σε υπηρεσία AI.

### Ενεργοποίηση δημοσίευσης

1. Στο αποθετήριο, άνοιξε **Settings → Pages**.
2. Στο **Build and deployment → Source**, επίλεξε **GitHub Actions**.
3. Στο **Actions → Deploy GitHub Pages**, πάτησε **Run workflow** αν η αρχική εκτέλεση απέτυχε πριν ενεργοποιηθεί το Pages.

Κάθε επόμενο push στο `main` ελέγχει την αναζήτηση και δημοσιεύει αυτόματα τη σελίδα. Το workflow ανεβάζει μόνο τα αρχεία της ιστοσελίδας, όχι το Python app ή τα PDF. Δεν απαιτούνται secrets.

### Τοπική προεπισκόπηση

```sh
python3 scripts/build_site.py
python3 -m http.server 8501 --directory _site
```

Άνοιξε `http://localhost:8501/`. Χρειάζεται HTTP server· το άνοιγμα του `index.html` ως `file://` δεν υποστηρίζει τη φόρτωση της βάσης γνώσης.

### Έλεγχοι

Με Node.js 22 ή νεότερο:

```sh
node --test tests/search.test.mjs
```

Οι έλεγχοι καλύπτουν όλες τις καταχωρίσεις, ελληνική κανονικοποίηση, σύντομες ερωτήσεις για ώρες και αμοιβή, αμφίσημες ερωτήσεις και αποχή όταν δεν υπάρχει σχετική απάντηση.

### Αρχεία

| Αρχείο | Ρόλος |
| --- | --- |
| `index.html`, `styles.css` | Ελληνικό, προσαρμοζόμενο περιβάλλον συνομιλίας |
| `app.mjs` | Συνομιλία, συχνές ερωτήσεις, θεματικές, χειρισμός αποτυχίας φόρτωσης |
| `search.mjs` | Αναζήτηση στη βάση γνώσης, χωρίς παραγωγή νέων πληροφοριών |
| `qa_data.json` | Κοινή βάση ερωτήσεων και απαντήσεων |
| `scripts/build_site.py` | Δημιουργία φακέλου `_site` για δημοσίευση |
| `.github/workflows/pages.yml` | Έλεγχοι και δημοσίευση στο GitHub Pages |
| `app.py`, `requirements.txt` | Αρχική εφαρμογή Streamlit |

## Ενημέρωση περιεχομένου

Επεξεργάσου το `qa_data.json`, διατηρώντας μοναδικό αριθμητικό `id` και τα πεδία `category`, `question`, `answer`, `keywords`. Το επόμενο push ενημερώνει την ιστοσελίδα. Για αλλαγές στην ορολογία της αναζήτησης, πρόσθεσε συνώνυμα στο `search.mjs` και αντίστοιχο έλεγχο.

**Προσοχή στις ημερομηνίες:** η υπάρχουσα βάση περιέχει πληροφορίες παλαιότερου ακαδημαϊκού έτους. Επιβεβαίωσε προθεσμίες και απαιτήσεις με τον υπεύθυνο πριν τις χρησιμοποιήσεις. Η ιστοσελίδα εμφανίζει σχετική επισήμανση. Τα επίσημα δικαιολογητικά υποβάλλονται στις πλατφόρμες του κολλεγίου.

## Αρχική εφαρμογή Streamlit

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Το GitHub Pages δεν εκτελεί Python ή κλήσεις Groq στον server. Η αρχική έκδοση `app.py` παραμένει διαθέσιμη για ξεχωριστή φιλοξενία Streamlit. Για generative AI στη στατική έκδοση χρειάζεται ξεχωριστό backend που διατηρεί το κλειδί Groq ιδιωτικό· **μην τοποθετείς API keys σε JavaScript, HTML ή Git**.
